重组和@Composeable

@Composable

被 @Composable 标记的方法，它叫“可组合函数（Composable Function）”。

它是一个静态的、描述性的 UI 生成模板。被它标记的代码，在编译时会被 Kotlin 编译器插件（Compose Compiler）疯狂“魔改”，在函数的参数列表里偷偷塞进一个叫 composer: Composer 的隐式参数。

它负责的是：“告诉我当前应该画什么 UI”。

重组

重组不是一个方法，而是一个由 Compose Runtime（渲染引擎）发起的“动作”。

当某个 mutableStateOf 的值发生改变时，Compose Runtime 内部会调度一个任务。这个任务会圈定受到影响的、最小的 @Composable 函数范围（被称为 RecomposeScope）。

mutableStateOf

mutableStateOf是一个快照容器，里面存储的具体内容，提供给每个访问者对应的快照版本。
